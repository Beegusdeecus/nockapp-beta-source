# Included saved-pack client source overlay

Copy the unchanged `browser-bulk-ticket-client-v4` source snapshot, then replace only the four rootfs source files listed in PARENT.json. The manifest is the full runtime file-hash inventory, not a claim that binaries are included. Owner configuration, registration, keys and private wallet records are excluded.

Client release12 permits an explicitly approved unarmed saved two-ticket pack to become the first of25packs in a50-ticket atomic payment. The original blinded inputs are retained in the pending slot until the complete encrypted batch and one-shot arm fence are durable. Recovery handles interruption before slot release. Existing payment/refund/closed history is not repurposed, latest/finalized unpaid checks precede adoption and dispatch, and old single-pack tabs cannot arm during an active batch. No new contract, AWS permission, enclave or service key is involved.
